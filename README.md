# Lifter File Viewer

A premium, state-of-the-art desktop visualizer application built with **React**, **Vite**, **TypeScript**, and **Electron**. It provides intuitive, interactive dashboard visualizations for various analysis output formats generated by the Lifter tooling suites.

---

## Supported Visualizations

The viewer dynamically detects file structures and maps them to appropriate visualizers:
- **Codebase Analyzer** (`project_analysis_result.json`): Comprehensive codebase audit dashboard, project inventories, technical stacks, versions, and integration details views.
- **.NET API Analyzer** (`api-report.json`): Comprehensive endpoint lists, HTTP method breakdowns, REST/MVC API distributions, parameters, and service types.
- **Consolidated Analysis** (`consolidated_analysis.json` / `consolidated_gims_analysis.json`): Process flow charts, domain breakdowns, and legacy systems analysis.
- **Module Analysis** (`module_analysis.json`): Module interactions, dependencies, and complex systems architecture layouts.
- **PlantUML Diagrams** (`*.puml`, `@startuml`): Rich UML rendering.
- **Mermaid Diagrams** (`*.mermaid`, `graph TD`, etc.): Interactive graph visualizations.
- **Unified Knowledge Graphs** (`unified_knowledge_graph.json`): Knowledge relationship mapping.
- **User Stories** (`user_stories.json`): User journey dashboards.
- **CycloneDX SBOM** (`cyclonedx-sbom.json`): Software Bill of Materials audits.
- **Security Reports** (`security-report.json`): Vulnerability mappings.

## One-Click Automated Setup

Automated scripts are available to automatically check/install prerequisites (Git, Node.js, npm), install project dependencies, package the application, bypass operating system security blocks, and launch the app immediately.

### On macOS / Linux:
Run the install bash file:
```bash
bash install.sh
```

### On Windows:
Double-click the standalone **`install.bat`** file (or run it from the Command Prompt). This script is completely self-contained; if the project source is not present, it will run `git clone` to download the codebase automatically. It bypasses execution policies, installs Git/Node.js via `winget` if missing, runs the installer/builder, unblocks the resulting executable, and opens the application.

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed. We recommend using **Bun** for faster package resolution and builds, but standard **NPM** is fully supported.

### Installation

Navigate to the project directory and install dependencies:

```bash
# Using Bun (Recommended)
bun install

# Using NPM
npm install
```

### Running in Development

To start the application locally with hot-reloading:

```bash
# Using Bun
bun start

# Using NPM
npm start
```

## Production Builds

### 1. Compile Assets
To verify code compilation and bundle the Vite React frontend:

```bash
# Using Bun
bun run build

# Using NPM
npm run build
```

### 2. Package Desktop Application
To compile frontend assets and package them into a native standalone desktop installer:

```bash
# Using Bun
bun run dist

# Using NPM
npm run dist
```

Packaging outputs are saved to the `dist_electron/` directory.

---

## Cross-Platform Packaging (.dmg & .exe)

Packaging is handled by `electron-builder`. By default, running the packaging commands on your operating system generates native builds for that platform (e.g. DMG on macOS, Portable EXE on Windows).

### Packaging for macOS (.dmg)
Generates a `.dmg` installer and `.app` package in the `dist_electron/mac-arm64/` (or `mac-x64/`) directory.

```bash
# Run on macOS:
bun run dist
# Or specifically target mac:
npx electron-builder --mac
```

### Packaging for Windows (.exe)
Generates a portable, self-contained `.exe` application in the `dist_electron/` directory.

```bash
# Run on Windows:
bun run dist

# Cross-compile from macOS:
npx electron-builder --win
```

### Target Multi-Platform
To build for both platforms simultaneously (on supported host machines):

```bash
npx electron-builder -mw
```

## Security & OS Activators

Since packaged apps are self-signed/ad-hoc signed, operating systems may flags files as suspicious or block execution upon download. Use the provided activator scripts to resolve this.

### macOS Activation (`setup.command`)
If macOS blocks execution with a Gatekeeper warning or quarantine error:
1. Drag the `Lifter-File-Viewer.app` to your `/Applications` folder.
2. Double-click the `setup.command` script in this folder to run `xattr -c` and automatically lift security restrictions.

### Windows Activation (`setup_win.bat`)
If Windows SmartScreen blocks launch:
1. Place `setup_win.bat` in the same directory as your generated `Lifter-File-Viewer 1.0.0.exe`.
2. Double-click `setup_win.bat` to run the PowerShell `Unblock-File` cmdlet and allow execution.
